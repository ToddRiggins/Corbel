Corbel examples

Each page runs a full scene on this dev server. Append ?backend=webgl2 to any of them to force the fallback renderer.

  • Point lights — OmniLight3D, SpotLight3D, and emission
  • Shadow maps — DirectionalLight3D.shadow_enabled
  • Materials — texture maps, uv transform, emission, alpha, fog
  • ShaderMaterial textures — set_shader_parameter with a Texture2D
