Corbel

How to use it, and how to program with it. This page grows as the engine grows.

History · Foundation plan

What it is

Corbel is an HTML5 creation engine. Games run on it. The future VoxiTect editor runs on it. You write TypeScript. The names of the types and methods follow Godot 4, so a script can move between GDScript and Corbel with small edits.

React is for panels, menus, and the site page. The scene tree, once it exists, owns the 3D world. That part is not built yet.

What you can do today

Slice 1 is in @corbel/core. You can do math: positions, directions, rotations, colors, planes, and boxes. You cannot add a node, draw a mesh, or pick a voxel yet. Those are the next slices.

From the Corbel folder:

npm test

That runs the checks that the numbers still match Godot.

A first script

import { Basis, Transform3D, Vector3 } from "@corbel/core";

const camera_pos = new Vector3(0, 1.5, 4);

// A character at the origin. Local +Z points at the camera.
const facing = Transform3D.IDENTITY.looking_at(camera_pos, Vector3.UP, true);

// A camera looks the other way: local -Z points at the target.
const look = Basis.looking_at(new Vector3(0, 0, -5));

The world is Y-up and right-handed. Vector3.FORWARD is (0, 0, -1). A camera looks down -Z. A character that faces the camera looks toward +Z. Pass true as the third argument of looking_at when you want that character facing.

Where GDScript and Corbel differ

TypeScript has no + for these types. A method does the same job.

// GDScript
var mid := a.lerp(b, 0.5)
var sum := a + b
var scaled := a * 2.0

// Corbel
const mid = a.lerp(b, 0.5);
const sum = a.add(b);
const scaled = a.mul(2);

The method names that already match are unchanged: length(), normalized(), dot(), cross(), lerp(), distance_to().

In 2D, Godot's Y points down the screen. Vector2.UP is (0, -1). In 3D, Y points up. Vector3.UP is (0, 1, 0).

Colors, cells, and the ground

import { AABB, Color, Plane, Vector3, Vector3i } from "@corbel/core";

const orange = Color.html("#ff8000");
const cell = new Vector3i(2, 0, -1);
const above = cell.add(Vector3i.UP);

const ground = new Plane(Vector3.UP, 0);
const hit = ground.intersects_ray(new Vector3(1, 2, 3), new Vector3(0, -1, 0));
// hit is (1, 0, 3). A ray that points away comes back null.

const box = new AABB(new Vector3(0, 0, 0), new Vector3(2, 2, 2));
box.has_point(box.get_center());

Vector3i truncates toward zero. A voxel cell will be one of these. The volume that stores cells is not written yet.
