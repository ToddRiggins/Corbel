ArrayMesh

Inherits: Mesh < Resource < Object

A mesh that holds a mutable list of surfaces built at runtime.

Description

ArrayMesh keeps surfaces you add yourself. add_surface_from_arrays appends one surface (PrimitiveType plus its SurfaceArrays), surface_get_primitive_type, surface_get_name / surface_set_name and surface_get_material / surface_set_material read or change the surface's settings, and surface_remove or clear_surfaces take them away. Indices must point at real vertices, or building throws. custom_aabb shrinks the measured AABB when set. A constructor that gets SurfaceArrays builds the same single TRIANGLES surface as before.
