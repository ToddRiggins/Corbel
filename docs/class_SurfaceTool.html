SurfaceTool

Inherits: Object

Builds a mesh one vertex at a time, the way Godot's SurfaceTool does.

Description

SurfaceTool builds a mesh with triangles, vertices, normals, colors, UVs, and tangents, and commit hands back an ArrayMesh. begin(PrimitiveType.TRIANGLES), set per-vertex attributes, add_vertex to close each one. Pending attributes reset after every vertex. commit returns an ArrayMesh.
