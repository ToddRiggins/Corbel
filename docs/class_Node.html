Node

Inherits: Object

Base class for everything that lives in a scene tree.

Description

Node is the base class for everything in a Corbel scene tree. A node has a name, an optional parent, children, an owner, and groups. The tree calls lifecycle methods in order: _enter_tree when the node joins the live tree, _ready after the children are ready (children run before the parent, like Godot), _process once per frame, _input on every event that the runner feeds the tree, and _exit_tree when the node leaves. queue_free removes the node at the end of the frame. Scripts get these hooks by overriding them with the same names in TypeScript: a class extends Node (or a subclass) and overrides _ready(). Throw nothing you cannot survive: a throw inside _ready or _process is reported through SceneTree.on_node_error and the frame keeps running.
