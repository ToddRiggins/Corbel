Node3D

Inherits: Node < Object

Base for nodes with a place in 3D space: position, rotation, basis, visibility.

Description

Node3D adds a place in 3D space. rotation is stored as a Basis and written back through rotation (radians) or rotation_degrees. transform composes both into a Transform3D. Every subclass that draws or moves inherits this class. The world is Y-up and right-handed; a camera looks down local -Z, so a node authored to face the camera points its +Z at it.
