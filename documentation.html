What this is

Corbel is an HTML5 creation engine. Games will run on it, and the VoxiTect editor will run on it. You write TypeScript. Method names follow Godot 4, so a script can move toward GDScript with small edits.

The world is Y-up and right-handed. Vector3.FORWARD is (0, 0, -1). A camera looks down −Z. A character that faces the camera looks toward +Z.

TypeScript has no + for these types. Call a method: a.add(b), a.mul(2), a.lerp(b, 0.5). In 2D, Y points down the screen, so Vector2.UP is (0, -1). In 3D, Vector3.UP is (0, 1, 0).

The package is @corbel/core. Import from that name. React draws the editor. It does not own the scene.

These pages

documentation.html is this reference. tutorial.html is the short how-to. history.html is the log of what changed. Keep all three current when the engine gains a feature.

In the editor, Help opens each page in a new window. On disk they sit next to each other in the Corbel folder, so a double-click opens one too.

Layout

Double-click start_editor.bat, or run npm run editor from the Corbel folder. The page is http://127.0.0.1:5177/.

Scene and FileSystem are on the left. The 3D workspace and Output sit in the middle. The Inspector is on the right. Output is only as wide as the middle. Drag a splitter to resize a dock.

The top bar has Scene, Project, and Help, then 3D and Script, then Play, Pause, and Stop. Play stays off until a canvas can draw the scene. Scene → New 3D Scene makes a Node3D named Main. Scene → Save writes the open .cscene. Ctrl+S saves the scene, or the open script when Script is showing.

Projects are folders under projects. The demo is projects/demo. res:// means a file inside the open project. The Project menu switches projects.

Scene dock

Each row is the node’s name. The type is in the Inspector, not on the row. The arrow folds the children. A node with no children has no arrow. The eye on a 3D node hides and shows it. A blue TS means a script is attached.

Add names the new node after its type. A second node of that name under the same parent becomes Name2, then Name3. A different parent may use the same name. Rename from the right-click menu or from the Inspector. Drop a row onto another row to parent it.

Right-click a row. The browser menu stays closed. The menu today is:

  • Add Child Node
  • Attach Script, and Detach Script when one is attached
  • Expand Branch and Collapse Branch when the node has children
  • Rename
  • Copy Node Path
  • Delete

Later, if we need them: sub-resources, instancing a scene, cut, copy, duplicate, extend script, change type, move up and down, reparent dialogs, make scene root, save branch as scene, unique name, and class documentation from the row.

Script replaces the plain text box. The colors follow the same split Godot uses for GDScript. Each kind of code has its own color, listed under the editor:

The colors live in apps/editor/src/script/roles.ts. The parser tags live in highlight.ts. Change a role there when a kind of code should look different.

A− and A+ change the code font from 12 to 32. The size is remembered on this computer. Line numbers, the current line, matching brackets, and folding are on. Ctrl+F finds text in the file. A red underline is a TypeScript error. Click the line under the editor to jump there. The message includes the file, the line, the column, and “Did you mean” when TypeScript knows a close name.

Right-click a documented name, such as Node3D or _process, and choose Look up. The reference opens in its own window with that name at the top. A name with no entry keeps the browser menu.

Scene file

A scene is JSON, format 1, in a .cscene file. The demo opens res://main.cscene because project.corbel.json sets main_scene.

{
  "format": 1,
  "type": "Node3D",
  "name": "Main",
  "position": [0, 0, 0],
  "children": [
    { "type": "Camera3D", "name": "Camera", "position": [0, 1.5, 4] }
  ]
}
FieldMeaning
typeNode, Node3D, Camera3D, or MeshInstance3D
nameThe name shown in the scene dock
position[x, y, z] on a 3D node
rotation_degrees[x, y, z] in degrees
visibleWrite false to hide a 3D node. Omitted means visible
scriptA res:// path to a .ts file
childrenThe same kind of object, nested

pack_scene writes a node. unpack_scene builds one. The caller adds that node to a SceneTree.

A script

Attach Script on a node. The path starts as res://Name.ts. If that file is missing, the editor writes a class that extends the node’s type and opens it. If the file is already there, it attaches and opens it and does not replace the text.

import { Node3D } from "@corbel/core";

export default class Player extends Node3D {
  speed = 2;

  override _process(delta: number): void {
    this.position.x += this.speed * delta;
  }
}

The checks that run on a node, in order:

  • _enter_tree on the parent, then on each child.
  • _ready on the children, then on the parent. _ready runs once, even if the node is removed and added again.
  • _process(delta) on the parent, then the children, each frame.
  • _exit_tree on the children, then the parent.

The editor typechecks the file. Play does not run the scene yet, so an attached script is not called from the editor until the canvas slice exists. npm run try still runs packages/try/src/main.ts from the terminal.

Override _enter_tree, _ready, _process, and _exit_tree. Leave them empty when a node has nothing to do. A throw in _ready or _process does not stop the tree; SceneTree.on_node_error receives the node and the error.

Node3D

Node3D adds a place in 3D space. position is a Vector3. basis is the rotation. visible hides the node. The eye in the scene dock and the Inspector checkbox write the same flag.

PropertyJob
positionLocal translation
rotationEuler radians. Setting it replaces the basis
rotation_degreesThe same rotation in degrees
basisThe rotation, stored as a Basis
transformBasis plus position as a Transform3D
visibletrue until something hides it

Copy a basis or a vector before you keep it. The constants on Basis and Vector3 are shared.

Camera3D and MeshInstance3D

Camera3D is the view. fov is vertical degrees, 75 like Godot. near and far clip it. current picks the camera: the last current camera in tree order draws, or the first camera when none is current. MeshInstance3D draws its geometry when it holds a mesh, and material_override carries the color. Both can be added, moved, hidden, and saved.

create_node(type) builds one of Node, Node3D, Camera3D, or MeshInstance3D. node_label(node) is the type the Inspector shows.

Drawing

SceneTree.init({ canvas, preference }) picks a renderer and starts the frame loop: _process(delta) in tree order, then a draw. renderer_name reads webgpu or webgl2. close() stops the loop. The backend is WebGPU when the browser has it, and WebGL2 otherwise. GeometryInstance3D is the base a renderer can draw.

A mesh is a BoxMesh(size) cube or an ArrayMesh(arrays) with positions, normals, colors, and indices. StandardMaterial3D carries albedo, roughness, and metallic. DirectionalLight3D shines along the node’s -Z with light_color. The first light in tree order lights the scene.

const cube = new MeshInstance3D();
cube.geometry = new BoxMesh(new Vector3(1.6, 1.6, 1.6));
tree.get_root().add_child(cube);
await tree.init({ canvas, preference: "webgpu" });

SceneTree and Signal

new SceneTree() makes a hidden root named root. Add the scene’s top node with get_root().add_child(scene). Call _process(delta) once per frame. That walks the tree, then removes anything that called queue_free.

MethodJob
get_root()The hidden root
get_nodes_in_group(group)Every node that joined that group
_process(delta)One frame. Parent first, then children, then queued frees
init({ canvas, preference })Pick the renderer and start the frame loop
renderer_namewebgpu, webgl2, or null before init
close()Stop the loop and release the renderer
pausedSkip _process while it is true; the draw still happens
on_node_errorSet a callback to receive _ready and _process errors with the node

A Signal is a list of callbacks. connect adds one. disconnect removes it. is_connected checks. emit(...args) calls them in the order they were connected.

const hit = new Signal<[number]>();
hit.connect((amount) => { /* use amount */ });
hit.emit(3);

Vectors

Vector3 is x, y, z. Vector2 is x, y. Vector3i is the integer form used for a cell. Methods return a new value unless the name says the vector changes itself. normalize() changes this vector. normalized() returns another.

Shared directions: ZERO, ONE, LEFT, RIGHT, UP, DOWN. Vector3 and Vector3i also have FORWARD (0, 0, -1) and BACK (0, 0, 1).

Vector3Job
length() length_squared()How long it is
normalize() normalized() is_normalized()Make the length 1
dot(v) cross(v)Dot product, and a perpendicular vector
add sub mul div negArithmetic. mul and div take a number or a vector
lerp(to, weight)Blend. Weight 0 is this vector. Weight 1 is to
distance_to distance_squared_to direction_to angle_toMeasures toward another vector
abs() inverse()Per component
get_any_perpendicular()Some vector at a right angle
is_equal_approx(v) is_zero_approx()Close enough, using CMP_EPSILON which is 0.00001
clone() component(index)A copy, or x, y, or z by 0, 1, or 2

Vector2.cross returns a number, not a vector. Vector3i has add, sub, mul, length, length_squared, to_vector3, and is_equal. It truncates toward zero when a value is not already an integer.

is_equal_approx(a, b) and is_zero_approx(a) compare plain numbers.

Rotation

A Basis is a 3×3 rotation and scale. Rows are stored. .x, .y, and .z are the columns, which are the local axes. Basis.IDENTITY is no rotation.

BasisJob
from_euler(radians)YXZ order, which is Godot’s default
looking_at(target, up, use_model_front)Aim. target is a direction. With use_model_front, local +Z points along it, so a character faces the camera. Without it, local −Z points along it, so a camera looks
from_columns(x, y, z) from_scale(scale)Build one from axes, or from a scale
get_column(index) get_euler() get_quaternion()Read it back
xform(v) xform_inv(v) mul(basis)Apply it
transposed() inverse() determinant()The other directions
is_equal_approx(basis)Close enough

A Quaternion is x, y, z, w. Identity is (0, 0, 0, 1). It has from_euler, length, normalized, dot, inverse, mul, xform, slerp, get_euler, is_equal_approx, and is_zero_approx.

A Transform3D is a basis plus an origin. IDENTITY is unmoved. xform(point) moves a point. looking_at(target, up, use_model_front) returns a new transform aimed at a point. translated(offset) shifts the origin. is_equal_approx compares two transforms.

import { Transform3D, Vector3 } from "@corbel/core";

const camera_pos = new Vector3(0, 1.5, 4);
const facing = Transform3D.IDENTITY.looking_at(camera_pos, Vector3.UP, true);

Plane, box, and color

A Plane is a normal and a distance d. new Plane(Vector3.UP, 0) is the ground. from_point_normal(point, normal) builds one. distance_to(point) and project(point) measure and drop a point onto the plane. intersects_ray(from, dir) returns the hit, or null when the ray points away.

An AABB is a corner position and a size. get_center and get_end read it. has_point tests a point. intersects tests another box. expand(point) and merge(other) grow it.

A Color is r, g, b, a from 0 to 1. WHITE and BLACK are ready. Color.html("#ff8000") reads #rgb, #rrggbb, or #rrggbbaa. to_html() writes #rrggbb, and to_html(true) includes the alpha.

const ground = new Plane(Vector3.UP, 0);
const hit = ground.intersects_ray(new Vector3(1, 2, 3), new Vector3(0, -1, 0));
// hit is (1, 0, 3)

A voxel cell will be a Vector3i. The volume that stores cells is not written yet.
