2026-11-18

  • Named the engine Corbel. GodotJS was already a different project, TypeScript inside Godot, so that name stayed unused.
  • Wrote FOUNDATION.md. The engine keeps Godot 4 names, prefers WebGPU with a WebGL2 fallback, and treats voxel picking as a first feature. React draws UI only.
  • Started slice 1. @corbel/core has Vector2, Vector3, Vector3i, Quaternion, Basis, Transform3D, Plane, AABB, and Color. Thirteen tests check them, including Vector3.FORWARD and a looking_at that faces +Z toward the camera.
  • Added this history and tutorial.html.
  • Opened the GitHub repository ToddRiggins/Corbel.
